# Reference

`original-prototype.html` is the source recovered from the Claude design export
(`UrbanQuest Inc - Standalone.html`), which shipped as a self-extracting bundle
with the page source and assets base64-encoded inside it.

It is kept only as provenance for the original design intent. It is **not** part
of the site and is not served — it references assets by UUID and compiles JSX in
the browser via Babel. The shipping site is the files in the parent directory.
